# Diagramas editables en Draw.io

234 versiones derivadas de las fuentes PlantUML del proyecto. Conservan coordenadas, colores y textos del SVG original; no son capturas incrustadas. Los textos son celdas editables y los trazos son formas vectoriales. Los archivos .puml y PNG originales siguen siendo la fuente de diseño.

Abrir un archivo .drawio con diagrams.net o la aplicación Draw.io. Las flechas se conservan como primitivas gráficas, no como conectores semánticos reanclables; para regenerar un cambio estructural conviene editar el PlantUML. El manifiesto relaciona cada archivo y su cantidad de objetos.

El conversor conserva la apariencia y no cambia el significado de los diagramas ni la versión histórica que representan.
